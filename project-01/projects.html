Projects

A collection of small HTML projects built while learning front-end development, focused on semantic structure, accessibility, and multi-page website development.

Personal Website

A multi-page personal website built using HTML, including a homepage, about page, projects page, and contact page. This project was my first structured attempt at building a personal portfolio.

Purpose

To practise building structured web pages and understand how multiple pages connect within a single website.

Skills Used

  • HTML structure
  • Semantic elements (header, main, footer, section)
  • Navigation links
  • Anchor links (a)

Key learning outcomes

This project helped me understand how to structure a webpage properly using semantic HTML. It improved my understanding of how content is organised into sections and how separate pages work together within a site.

Challenges

The main challenge was starting from a blank page and deciding what content to include and where it should sit within the structure. I also initially found it difficult to understand correct heading hierarchy.

Improvements for next time

  • Plan page structure before writing code
  • Improve clarity in content organisation
  • Continue building confidence starting from scratch

About Me Page

A structured page presenting my background, learning journey, and interests as part of my personal website.

Purpose

To practise organising personal information into clear, structured web content using semantic HTML.

Skills used

  • Section-based layout
  • Lists and structured content
  • Heading hierarchy
  • Writing for web readability

Key learning outcomes

This project improved my ability to break information into clear sections and use headings to guide structure and readability. It also helped me move from informal writing to more structured, professional content.

Challenges

Deciding what personal information to include and how to present it in a professional tone rather than a conversational one.

Improvements for next time

  • Keep content concise
  • Maintain a consistent professional tone
  • Plan structure before writing

Reflection

What is improving

I am becoming more confident in building page structure using semantic HTML and organising content into clear sections.

What is still challenging

Starting from a blank page without guidance and deciding what content belongs where.

What helped most

Breaking pages into smaller sections rather than trying to design the whole page at once.

Focus going forward

Improving confidence in planning and building pages independently without relying on step-by-step guidance.

Future Projects

  1. Styling this website with CSS
  2. Improving layout and visual design
  3. Expanding portfolio with additional structured projects as I continue learning
